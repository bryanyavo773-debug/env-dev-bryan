# Aide-mémoire du terminal Linux

## Se déplacer

| Commande | Ce qu'elle fait               | Exemple    |
| -------- | ----------------------------- | ---------- |
| `pwd`    | Affiche le dossier où je suis | `pwd`      |
| `cd`     | Change de dossier             | `cd ~/dev` |

## Fichiers et dossiers

| Commande | Ce qu'elle fait  | Exemple          |
| -------- | ---------------- | ---------------- |
| `cp`     | Copie un fichier | `cp a.txt b.txt` |
