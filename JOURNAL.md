# Journal des choix

## 2026-11-14 – Installation de Node.js

- **Décision :** installer Node.js avec le dépôt NodeSource et apt.
- **Autres possibilités :** le paquet nodejs d'Ubuntu, le site nodejs.org.
- **Raison :** NodeSource donne la version LTS récente, et les commandes
  peuvent être écrites dans mon README pour être refaites à l'identique.

## 2026-11-14 – Système pour le terminal

- \*\*Décision :\*\* utiliser le terminal Linux (Bash).

- \*\*Autres possibilités :\*\* Zsh, Fish ou PowerShell.

- \*\*Raison :\*\* Bash est installé par défaut sur de nombreuses distributions Linux. Il permet d'exécuter les commandes nécessaires pour gérer les fichiers, installer des logiciels et travailler avec Git et Node.js.

## 2026-11-11 – Installation de tree

- **Décision :** Installer l'outil `tree` avec la commande `sudo apt install tree`.
- **Alternatives envisagées :** Utiliser la commande `ls` ou installer un autre outil d'affichage des dossiers.
- **Raison :** `tree` permet d'afficher l'organisation des fichiers et des dossiers sous forme d'arborescence. Cela facilite la visualisation et la compréhension de la structure du projet.

## 2026-11-13 - hébergement du dépôt : Github

## 2026-11-13 – Hébergement du dépôt : GitHub

- **Décision :** Héberger le dépôt du projet sur GitHub.
- **Alternatives envisagées :** GitLab, Bitbucket et conserver le projet uniquement en local sur l'ordinateur.
- **Raison :** GitHub permet de sauvegarder le code en ligne, de suivre les modifications avec Git, de retrouver les anciennes versions du projet et de partager facilement le travail avec d'autres développeurs.
